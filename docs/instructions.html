Build your own band site

Use this demo as a layout reference for a site you own.

  1. Create a repository in your own GitHub account. Connect that repository to a Codex Cloud environment in ChatGPT.
  2. Attach your logo, wide hero artwork, live photos you can publish, approved bio, booking contact, social links, and confirmed show details.
  3. Ask Codex to build Home, Shows, Photos, Video, The Band, and Booking in the repository’s docs/ folder. Ask it to open a pull request for you to review.
  4. After merging, open GitHub Settings → Pages and select main and /docs. Use the link GitHub provides to check the published site.

Save your site rules

Create a ChatGPT Project called Band Website Manager and paste your preferences into its Project instructions. Keep the same rules in AGENTS.md in your repository so Codex can read them when you start a separate task.

Copy for a show update

Read AGENTS.md in my connected band website repository. Add this confirmed gig to Shows and update the homepage if it is the next date. Use the attached flyer. Details: [date, time zone, venue, address, cover, age limit, and ticket link]. Preserve the current design. Flag conflicting facts and open a pull request for review.
